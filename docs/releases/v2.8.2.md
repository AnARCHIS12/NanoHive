## v2.8.2 - Base image and CI dependency updates

Maintenance release. No change to the theme itself (UI, settings, ratings API): only the components it is built and shipped with were updated. The previous image still ran nginx 1.27.4, published in February 2025.

### Security
nginx 1.31.8 is not affected by any of the 26 nginx advisories published in 2026 (see nginx.org/en/security_advisories): every one of them is fixed in 1.31.7 or earlier. The previous 1.27.4 image was within the affected range of 22 of them, including `CVE-2026-42533` (buffer overflow with `map` and regex, severity major), `CVE-2026-56434` (use-after-free in the SSI module, which this theme uses to inline its payload into HTML), `CVE-2026-9256` and `CVE-2026-42945` (rewrite module), `CVE-2026-60005` (slice module), `CVE-2026-95101` (HTTP/3), `CVE-2026-97629` (TLS session tickets) and `CVE-2026-97205` (AIO). The Alpine base layer was last rebuilt upstream on 2026-11-13.

### Runtime image
- `nginx` 1.27.4-alpine to **1.31.8-alpine** (this is the image that runs in production and is exposed to clients). Brings all nginx and Alpine base-system fixes released since February 2025.

### Build stage (not shipped in the final image)
- `node` 22.14.0-alpine to **22.23.5-alpine**.
- `esbuild` 0.24.2 to **0.28.2** (theme minification).

### CI and supply chain
- GitHub Actions bumped, all still pinned by commit SHA: `actions/checkout` v4.2.2 to v7.0.1, `docker/setup-qemu-action` v3.2.0 to v4.4.0, `docker/setup-buildx-action` v3.7.1 to v4.4.1, `docker/login-action` v3.3.0 to v4.8.0, `docker/metadata-action` v5.6.1 to v6.2.0, `docker/build-push-action` v6.9.2 to v7.4.0, `actions/configure-pages` v5.0.0 to v6.0.0, `actions/upload-pages-artifact` v3.0.1 to v5.0.0, `actions/deploy-pages` v4.0.5 to v5.0.1.
- New `.github/dependabot.yml`: weekly update proposals for the Docker base images and the GitHub Actions.
- New release workflow: the GitHub release is now created automatically when a `v*` tag is pushed, and its notes are read from `docs/releases/<tag>.md`.
- `THEME_VERSION` set to `v2.8.2`.

### Verification
Image built from scratch; `nginx -t` passes on 1.31.8; the njs module loads and the `/_nh/api/*` routes are served; `/_nh/core.js` and `/_nh/server-config.json` answer 200; the container healthcheck reports `healthy`.

### Upgrading
Your settings are kept as long as `/data/nh` is on a volume (server preferences, ratings, logo, series covers, avatars). Environment variables are unchanged.

```bash
docker compose pull abs-theme && docker compose up -d abs-theme
```
