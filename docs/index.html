NanoHive Secure Edition

NanoHive Secure Edition is a standalone visual styling reverse proxy for Audiobookshelf (ABS). It injects a refined, cinematic theme directly into web interface pages without modifying or touching your underlying Audiobookshelf server.

Hardened & Sovereign Edition
This edition has been thoroughly purged of third-party network dependencies (abs-tract daemon, Goodreads scraping, Hardcover synchronization, Google Fonts, cross-user listening tracking). It operates in a strict closed-circuit, 100% offline-ready mode.

Cinematic Aesthetics

12 refined dark palettes, custom hex accent colors, and native high-legibility system typography.

Zero Network Leaks

No external calls to Google Fonts or public CDNs. Strict Content Security Policy (CSP) blocking any unauthorized outbound request.

Isolated Port 13379

No port collisions with overloaded port 8080. Placed immediately next to Audiobookshelf default port 13378.

Full Mobile Responsiveness

Optimized drawer navigation, touch-friendly controls, fluid responsive scaling, and zero horizontal overflow.

Differences from Upstream NanoHive

The original upstream repository contained several telemetry features and third-party network scrapers. Here is the direct architectural comparison:

Feature Upstream NanoHive NanoHive Secure Edition
Default Host Port 8080 (common conflict) 13379 (dedicated & conflict-free)
Web Fonts External calls to fonts.googleapis.com Native System Fonts (Zero external queries)
Goodreads Scraper (abs-tract) Go daemon + Amazon/Goodreads background scraping Completely Removed
Hardcover Relay Nginx GraphQL relay to api.hardcover.app Completely Removed
Social Listening Tracking Tracks and shares listening progress across users Disabled & Purged (Privacy Preserved)
Security Headers Basic configuration Strict CSP, X-Frame-Options, X-Content-Type-Options

Quick Start

Deployment takes under two minutes using Docker Compose. Simply position the proxy container in front of your Audiobookshelf instance.

docker-compose.yml 
services:
  audiobookshelf:
    image: ghcr.io/advplyr/audiobookshelf:latest
    restart: unless-stopped
    expose:
      - "80" # Internal container port, no need to expose to host if using proxy

  abs-theme:
    image: ghcr.io/anarchis12/nanohive:latest
    # Or build locally: build: .
    restart: unless-stopped
    depends_on:
      - audiobookshelf
    ports:
      - "13379:80" # Web access port
    volumes:
      - nh_theme_data:/data/nh
    environment:
      ABS_UPSTREAM: "http://audiobookshelf:80"
      NH_APP_NAME: "My Library"
      NH_BASE_THEME: "warm"

volumes:
  nh_theme_data:

Start the containers in the background:

Terminal 
docker compose up -d

Access your enhanced web library at http://YOUR_SERVER_IP:13379.

Environment Variables

All environment variables are optional except for ABS_UPSTREAM:

Variable Default Description
ABS_UPSTREAM Required Address of your Audiobookshelf server (e.g. http://audiobookshelf:80)
NH_APP_NAME "" Custom library title displayed in the top-left corner
NH_BASE_THEME "warm" Default theme (warm, slate, black, navy, mocha, pine, etc.)
NH_ACCENT_COLOR "#e0c27a" Primary accent color in hexadecimal format
NH_MAIN_FONT "system-ui" Typography stack (defaults to system UI font)
NH_SHOW_HERO_CAROUSEL "true" Display the hero carousel of currently playing items on home screen
NH_SHOW_RATINGS "true" Self-hosted internal book ratings and reviews system
NH_PUBLIC_MODE "false" Enable public/guest mode for anonymous browsing of public libraries
NH_GUEST_USERNAME "guest" Audiobookshelf username for public guests
NH_GUEST_PASSWORD "" Audiobookshelf password for the guest user account
NH_PROXY_BUFFER_SIZE "16k" Nginx upstream header buffer (essential for large OIDC tokens)

Public / Guest Mode (Public Podcasts & Audiobooks Instance)

Running an open Audiobookshelf instance to share public podcasts or curated audiobooks freely with the world without exposing your personal libraries is now turnkey.

Zero-Friction Browsing with Native Audiobookshelf Permissions
Visitors land directly on your library and can play podcasts immediately without facing an Audiobookshelf login form. Private libraries remain completely hidden, governed strictly by Audiobookshelf's internal user permission model.

How to Setup in 3 Simple Steps

  1. Create the Guest Account in Audiobookshelf:

    Go to your Audiobookshelf Admin Settings → Users → Add User. Create an account (e.g. username guest with a secure password). Under Permissions, check only your public libraries (e.g. Podcasts), and ensure all administrative, delete, and download rights are unchecked.

  2. Configure NanoHive:

    Either add the environment variables in your docker-compose.yml:

    docker-compose.yml 
    environment:
  - ABS_UPSTREAM=http://audiobookshelf:80
  - NH_PUBLIC_MODE=true
  - NH_GUEST_USERNAME=guest
  - NH_GUEST_PASSWORD=your_guest_password

    Or configure it dynamically from the web UI: sign in as admin, click the Theme button → Administration tab → Public / Guest Mode, enter credentials and save.

  3. Seamless Owner Sign-in:

    Whenever you (the instance owner or an authorized user) need to log into your private account, simply click the amber Connexion / Sign in button in the top navigation bar (or visit /login?admin=1). This bypasses the guest auto-bootstrap and presents the standard login form.

Security & Credential Protection
The guest password is never transmitted to client browsers. NanoHive's internal Nginx JavaScript module (NJS) performs an internal subrequest to Audiobookshelf's /login endpoint, issues a scoped guest bearer token, and caches it securely for 6 hours.

Zero-Leak Guarantee & Security

NanoHive Secure Edition follows defense-in-depth security principles:

1. Strict Content Security Policy (CSP)

The internal Nginx proxy enforces a restrictive CSP header on every served response:

Nginx Header 
Content-Security-Policy: default-src 'self'; script-src 'self' 'unsafe-inline' 'unsafe-eval'; style-src 'self' 'unsafe-inline'; img-src 'self' data: blob:; font-src 'self' data:; connect-src 'self' ws: wss:; media-src 'self' blob:; frame-ancestors 'self';

Even if any script attempts an external connection, the browser automatically blocks it.

2. Server-Side Authentication Verification

All API requests to the theme endpoints (/_nh/api/) are validated by Nginx using auth_request. The user Bearer token is validated against Audiobookshelf's /api/me endpoint. Unauthenticated clients cannot modify ratings, settings, or metadata.

Removed Components

To guarantee complete privacy and reliability, the following elements were completely excised:

  • abs-tract daemon: The auxiliary Go service that scraped Goodreads was deleted.
  • Google Fonts preconnects: Typography now relies exclusively on clean local system fonts.
  • Hardcover GraphQL proxy: Neutralized along with all related upstream network configurations.
  • Cross-user listening statistics: Internal tracking of progress across accounts was decommissioned.

Storage & Persistence (/data/nh)

All persistent state is stored cleanly inside the mounted volume at /data/nh:

  • ratings.json: Internal star ratings and written reviews.
  • config.json: Server-wide display preferences and active toggles.
  • logo.png: Optional custom library branding logo.
  • series-covers/: Cached custom artwork for series collections.

Custom Logo & Favicon

NanoHive includes complete visual identity and browser tab branding out of the box:

1. Default NanoHive Favicon

NanoHive comes pre-bundled with its official golden hexagon icon. The proxy automatically serves it at /_nh/favicon.png and intercepts direct browser requests for /favicon.ico, /favicon-32x32.png, and apple-touch-icon.png so your browser tabs display the theme icon immediately instead of the stock blue bookshelf icon.

2. Custom Logo Branding

You can easily substitute the default logo and favicon with your own custom artwork:

  1. Place your PNG or ICO image at /data/nh/logo.png in the mounted volume.
  2. Or specify an image URL/path with the NH_LOGO_URL environment variable.
  3. Reload your browser page: both the top-left appbar logo and the browser tab favicon will update automatically.

3. Dynamic Accent Tinting

When NH_COLORIZE_LOGO=true is enabled (or toggled in the Customizations panel), the logo and browser tab favicon are dynamically rendered onto an HTML5 canvas and tinted to match your chosen accent color in real time.

Reverse Proxy & OIDC

When running NanoHive behind an external reverse proxy (Nginx Proxy Manager, Traefik, Caddy, Cloudflare Tunnels):

Preserved OIDC Support
NanoHive faithfully forwards the incoming X-Forwarded-Proto header. Single Sign-On (Google, Authentik, Keycloak) callbacks function seamlessly without protocol mismatch errors.

Example Caddy configuration:

Caddyfile 
audiobooks.mydomain.com {
    reverse_proxy localhost:13379
}

FAQ & Troubleshooting

Why port 13379?

Audiobookshelf defaults to port 13378. Utilizing 13379 avoids port collisions with common tools that occupy 8080 (Traefik, Tomcat, Pi-hole, web development servers).

Do native mobile ABS apps still connect?

Yes. The Audiobookshelf mobile apps on Android and iOS connect directly to Audiobookshelf API endpoints through the proxy without any interference.

Where are theme preferences stored?

All persistent user configurations, ratings, and custom covers reside securely in the local Docker volume at /data/nh.
